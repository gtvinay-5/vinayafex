How to embed your CapCut / Motion link in HTML

1. Click Add Project or edit HTML directly.

2. In your project card, set the link like this:

<a href="https://www.capcut.com/template/…" target="_blank" data-app="capcut"> Open in CapCut </a>

Supported apps: capcut • alight • vn • aftereffects — the card will show the correct badge & redirect.

// COPY THIS TEMPLATE INTO HTML
<!-- PROJECT CARD TEMPLATE -->
<div class="project-card"
     data-link="YOUR_CAPCUT_LINK_HERE"
     data-app="capcut">
  <img src="THUMBNAIL_URL" />
  <h3>Project Title</h3>
  <a href="YOUR_CAPCUT_LINK_HERE"
     target="_blank">Open in CapCut</a>
</div>
TIP Replace YOUR_CAPCUT_LINK_HERE with your real share link. Anyone clicking the video will go there.
